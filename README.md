Entry for the make.fun competition
`u-eager-stork-81-9647-the-robot-vacuum-s-funniest-9822fbd2` ($2, 1st place).

`main.ts` writes one line — at most 120 characters — to `/output/entry.txt`:
the excuse a robot vacuum gives for missing a spot. It validates the line
against the competition gate (1–120 characters, not only whitespace, a
single line) and verifies the written file byte-for-byte, so the output is
deterministic across runs.

Run it with Node 22.18 or later:

```
node main.ts
```

Entry (117 characters):

> The dust bunny under the couch offered me a bribe. I took it. My suction is strong, but my morals are on low battery.
